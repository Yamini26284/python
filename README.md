# Python Learning Journey

My personal repository for tracking progress, notes, and exercises while learning Python in VS Code.

## 📂 Project Structure

- `main.py` - Core Python syntax and logic practice.
- `Notes/` - Written study notes and summaries.
- `errors.md` - Logs of common exceptions and how to fix them.
- `*.ipynb` - Interactive Jupyter Notebooks for deep dives (Strings, Comments).

## 🚀 How to Run

Make sure you have Python installed, then run the main file using:

```bash
python main.py
```
